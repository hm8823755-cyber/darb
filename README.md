إذا قصدك البرومبت حتى تنطيه للذكاء الاصطناعي ويسويلك تطبيق دَرب، هذا جاهز للنسخ 👇
أنشئ تطبيق Android احترافي باسم "دَرب" (DARB)، مخصص للعمل في العراق ويبدأ من مدينة الموصل.

فكرة التطبيق:
1. 🚕 خدمة تكسي:
- تحديد موقع الانطلاق والوجهة.
- عرض السعر التقريبي.
- طلب سيارة.
- تتبع السائق.
- معلومات السائق والسيارة.
- تقييم الرحلة.

2. 🍔 توصيل الطعام:
- عرض المطاعم.
- تصنيفات الطعام.
- قائمة الوجبات والأسعار.
- سلة المشتريات.
- تحديد عنوان التوصيل.
- متابعة حالة الطلب.
- تتبع مندوب التوصيل.

3. 🎁 نظام عروض وخصومات قوي:
- أول رحلة تكسي مجانية للمستخدم الجديد، مع إمكانية تحديد شروط وحد أقصى من لوحة الإدارة.
- عروض توصيل مجاني للأكل للمطاعم أو الطلبات المؤهلة.
- كوبونات خصم.
- عروض يومية وأسبوعية.
- نظام نقاط ومكافآت.

4. 👤 حساب المستخدم:
- تسجيل الدخول برقم الهاتف.
- الملف الشخصي.
- العناوين المحفوظة.
- الرحلات السابقة.
- طلبات الطعام السابقة.
- الكوبونات والنقاط.
- الدعم والشكاوى.

5. 🚗 تطبيق السائق:
- تسجيل السائق والسيارة.
- رفع المستندات للمراجعة.
- متاح/غير متاح.
- استقبال طلبات التكسي.
- قبول أو رفض الطلب.
- الملاحة.
- سجل الرحلات والأرباح.

6. 🛵 تطبيق مندوب الطعام:
- استقبال الطلبات.
- قبول الطلب.
- استلام الطلب من المطعم.
- تسليمه للزبون.
- تحديث حالة الطلب.

7. 🏪 لوحة تحكم الإدارة:
- إدارة المستخدمين.
- إدارة السائقين والمندوبين.
- إدارة المطاعم والوجبات.
- إدارة الرحلات والطلبات.
- تحديد أسعار التكسي والتوصيل.
- إنشاء وإيقاف العروض والكوبونات.
- التحكم بالرحلة المجانية والتوصيل المجاني.
- متابعة الأرباح والإحصائيات.
- إدارة الشكاوى.

التصميم:
- واجهة عربية RTL.
- تصميم حديث وسهل للمستخدم.
- اللون الأساسي أصفر مع أسود وأبيض.
- شعار بسيط باسم "دَرب".
- الصفحة الرئيسية تحتوي على:
  🚕 تكسي
  🍔 توصيل أكل
  🎁 الخصومات
- دعم الشاشات المختلفة للهواتف.
